# Telegram Supabase App

Setup integrasi antara Telegram Bot, Supabase Database, dan Deployment di Vercel.

## Fitur & Konfigurasi
- **Supabase**: Backend & Database
- **Telegram Bot**: Notifikasi / Chat interaction
- **Vercel**: Serverless Deployment & Hosting

## Konfigurasi Environment
Salin file `.env.example` menjadi `.env.local` lalu isi nilai yang sesuai:
```bash
cp .env.example .env.local
```

File `.env.local` sudah otomatis diabaikan oleh `.gitignore` demi keamanan kredensial.
